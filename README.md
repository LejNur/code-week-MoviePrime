# MoviePrime
MoviePrime is a web application inspired by Amazon Prime Video, allowing users to browse, search, and manage their favorite movies using The Movie Database (TMDb) API.

# Features
- Movie List: Display movies dynamically retrieved from TMDb API.
- Search Functionality: Filter movies by title.
- Favorites Management: Add and remove movies from favorites with user confirmation dialogs.
- Sorting: Sort movies by popularity.
- Category Filters: Filter movies by genre.
- Data Persistence: Favorites are saved and persist even after a page refresh.
- Multi-language Support: Available in Italian, English, French, and Spanish. Users can switch languages through a dedicated menu.

# UI/UX Highlights
- Responsive Design: Works seamlessly across devices.
- Semantic HTML5: Structured using semantic tags.
- Modern Layout: Implemented using Flexbox and Grid for clean, flexible design.
- Custom Styling: Aesthetic and user-friendly interface.
